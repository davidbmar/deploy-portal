⚡ Quick Start - What to Do After Download

📍 Step 1: Extract to the Right Location

IMPORTANT: Extract to a location Claude Code can access.

On Mac: 
# Create projects folder (if you don't have one)
mkdir -p ~/Documents/claude-projects

# Move the downloaded ZIP there
mv ~/Downloads/deployment-kit-*.zip ~/Documents/claude-projects/

# Navigate and extract
cd ~/Documents/claude-projects
unzip deployment-kit-*.zip
cd your-app-name/
On Linux/Windows: 
# Extract to your projects directory
mkdir -p ~/projects/claude-projects
mv ~/Downloads/deployment-kit-*.zip ~/projects/claude-projects/
cd ~/projects/claude-projects
unzip deployment-kit-*.zip
cd your-app-name/

🤖 Step 2: Deploy with Claude Code

  1. Open terminal in the extracted folder: 
    cd ~/Documents/claude-projects/your-app-name
  2. Start Claude Code: 
    claude-code
  3. Copy the deployment prompt: 
    cat CLAUDE_PROMPT.txt
    Then copy ALL the text and paste it into Claude Code.
  4. Press Enter and let Claude deploy your app automatically! 🚀

📦 What's in the Kit?

  • deploy-key.pem - SSH private key (keep secure!)
  • CLAUDE_PROMPT.txt - Ready-to-paste instructions for Claude
  • DEPLOY_INSTRUCTIONS.md - Human-readable deployment guide
  • app-config.json - Your app configuration details
  • README.md - Quick overview
💡 Pro Tip: The kit includes everything. Just extract, navigate to the folder in your terminal, start Claude Code, and paste the CLAUDE_PROMPT.txt contents. Claude will handle SSH connection, file uploads, port allocation, nginx configuration, and deployment!
